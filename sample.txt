Go to your repo on GitHub
Click the green "Code" button
Make sure HTTPS is selected
Copy the link shown there (looks like https://github.com/yourusername/reponame.git)
Then in your terminal:
bash

git remote add origin https://github.com/yourusername/reponame.git

Verify it got added:
bash

git remote -v

--------------------

 Whenever you make changes to your project, the usual Git workflow is:

1. Make changes to your files

2. git add .

3. git commit -m "Describe your changes"

4. git push origin main

git add stages the changes.
git commit saves those changes in your local repository.
git push uploads your committed changes to GitHub.
You only need to repeat these steps when you want to save and upload new changes. If you haven't made any changes, there's no need to commit or push.


--------------------


`git fetch` does not download only branches.

 

It downloads all the latest updates from the remote repository, including:

• New commits

• New branches

• Updated branch information

• Tags (if available)

 

It only updates your local repository's remote-tracking information. It does not merge the changes into your current branch.
